## 1. サービスは4タイプに分かれる

これを理解していないと比較が成立しない。

| タイプ | 代表例 | 物件数 | 情報の鮮度 | 使いどころ |
|---|---|---|---|---|
| **二次掲載型** | ニフティ不動産、Yahoo!不動産、スマイティ、goo住宅 | 最多（1,000万件超） | **最低** | 相場感の把握・初期の広く浅い探索 |
| **ポータル型** | SUUMO、LIFULL HOME'S、at home、カナリー、CHINTAI | 多い | 中 | 条件が固まってからの本命探し |
| **自社物件型** | いい部屋ネット、エイブル、ミニミニ、アパマン、UR、JKK | 少ない | 高 | そのブランドの物件を狙うとき |
| **業者DB連動型** | OHEYAGO、airdoor、XROOMS Pro、イエプラ、ietty | 最少 | **最高** | 内見直前・おとり物件を避けたいとき |

二次掲載型が物件数最多なのは「他サイトの情報を転載しているから」であって、実在する物件が多いという意味ではない。

## 2. おとり物件という前提条件

- 2021年の業界調査で、**ネット掲載物件の12%以上が実在しないおとり物件**だった
- 悪意のあるものだけでなく、**情報更新が週1回程度**のサイトでは決まった物件が最大1週間掲載され続ける
- 業者専用データベース（ATBB・レインズ・ITANDI BB）連動型はこの構造上おとり物件が出にくい
- 不動産情報サイト事業者連絡協議会（RSC）の**認定マーク**が付いているサイトは掲載情報の正確性に一定の担保がある

**ただし業者DB連動型も万能ではない。** airdoorは2024年10月時点で「申込済み物件が募集中と表示される事例」が複数報告されている。シャーメゾン（お部屋探しマスト）でも同様の事例あり。

## 3. 各サービスの外部評価

### ポータル型

| サービス | 評価されている点 | 指摘されている問題 |
|---|---|---|
| **SUUMO** | 業界シェアNo.1、物件数最多、写真が多い、SUUMOにしか載らない物件がある | **ポータル型の中でおとり物件が多い**、同じ物件が複数表示される、掲載業者で初期費用が変わる |
| **LIFULL HOME'S** | SUUMOに次ぐ規模、**おとり物件対策への取り組み姿勢が高く評価されている**、相場・アーカイブ等のコンテンツが充実 | 物件数はSUUMOに劣る |
| **at home** | 加盟店舗数が圧倒的（約59,000店 / HOME'S 約30,440店 / SUUMO 約20,370社）、**地場業者はSUUMOに載せずat homeに載せる場合がある** | 一般ユーザーの認知度・UIは劣後 |
| **カナリー（Canary）** | **AIでおとり物件を40%以上排除**、累計500万DL（2025年10月時点）、地図をなぞる検索が好評、電話不要でチャット/LINE完結 | エリアによって物件数が少ない、20〜30代向けUIで情報量は少なめ |
| **CHINTAI** | 歴史あり、エイブルグループ | 掲載企業がやや少ない |

### 業者DB連動型・チャット型

| サービス | 評価されている点 | 指摘されている問題 |
|---|---|---|
| **OHEYAGO** | ITANDI BB連動でおとり物件なし、**セルフ内見可**（不動産会社の立会いなし）、仲介手数料最大無料 | 2024年5月にリニューアルで掲載一時休止の経緯あり、対応エリア限定 |
| **airdoor** | 約8割が**仲介手数料無料**、大手管理会社物件に強い | **申込済み物件が募集中表示される事例が複数報告**（2024年10月時点） |
| **イエプラ** | 深夜0時までチャット対応、業者DBから提案、**実店舗がある安心感**、来店不要で内見まで完結 | **仲介手数料の割引がない**、「内見を急かされた」の声、条件が曖昧だと提案精度が落ちる、テキストのみで認識齟齬が起きやすい |
| **ietty** | **全物件の仲介手数料半額**、AI提案でしつこい営業がない | 提案待ちのため能動的な検索がしづらい |
| **XROOMS Pro** | ATBB連動でおとり物件ゼロ、仲介手数料最安0円 | **対応が東京・神奈川のみ**、写真が少ない、物件数が少ない、会員登録必須 |

### 公共系

| サービス | 評価されている点 | 指摘されている問題 |
|---|---|---|
| **UR賃貸住宅** | **礼金・仲介手数料・更新料・保証人がすべて不要**、初期費用は敷金2ヶ月＋日割家賃のみ、全国約70万戸 | 建物が古いものが多い、駅から遠い立地が多い、**SUUMOに掲載がない**ため自力で探す必要 |
| **JKK東京** | 民間より安価な家賃設定 | 競争率が高い、東京のみ |
| **ウチコミ** | 大家直接掲載で仲介手数料不要 | 物件数が少ない |

## 4. 金額に直結する2つの落とし穴

### ① 同じ物件でも問い合わせ先で初期費用が変わる

市場の約9割の物件はどの会社でも取り扱える。同じ部屋でも、問い合わせた会社によって仲介手数料・フリーレントの有無が変わり、**家賃1〜2ヶ月分の差が出ることがある**。気に入った物件は複数社で条件を比較すべき。

### ② キャッシュバックサイトは損をすることがある

賃貸スモッカ、賃貸EX、キャッシュバック賃貸、Door賃貸など。

- キャッシュバックの適用条件が厳しく、受け取れないことがある
- **仲介手数料を相場以上に取られてトータルで損をする**ケースがある
- キャッシュバック賃貸・Door賃貸は**自動的に複数社へ問い合わせが飛ぶ**（営業電話が集中する）

## 5. 今回のケースで特に効くもの：UR賃貸

`mit-2026.xlsx` の試算で家賃と並んで効いていたのが**更新料と初期費用**。URはこの両方が構造的にゼロになる。

| | 民間（家賃7万） | UR（家賃7万） |
|---|---|---|
| 礼金 | 7万 | **0** |
| 仲介手数料 | 7.7万 | **0** |
| 敷金 | 7〜14万 | 14万 |
| 保証会社 | 3.5万 | **0** |
| 初期費用（引越6万＋家具家電35万込） | **約72.5万** | **約55万** |
| 更新料（2年ごと） | 7万 | **0** |
| 実質貯蓄率（中程度削減時） | 21.6% | **22.4%** |
| 2,000万到達 | 11.8年 | **11.4年** |

さらに**入居資格の面で有利**。URは「平均月収が家賃の4倍以上」または「貯蓄額が月額家賃の100倍以上」が基準とされる。家賃7万なら貯蓄700万が必要だが、**現預金822万で余裕をもってクリアする**。

デメリットは築古が多いこと、駅から遠い物件が多いこと。ただし前回の整理どおり6万円台でも1LDK 40m²超が取れるエリアを見ているので、**築年数の新しさを優先しないなら相性は良い**。

## 6. 推奨する探し方の順序

1. **相場把握（今ここ）** — ニフティ不動産か各サイトの相場ページ。実在性は気にせず、エリアと価格帯の感覚をつかむ
2. **条件の絞り込み** — SUUMO＋LIFULL HOME'S＋at homeの3つを並行。at homeは地場業者物件が拾えるので外さない
3. **おとり回避しつつ本命探し** — カナリー（AI排除）を併用。埼玉・千葉なら対応エリア内
4. **UR賃貸を必ず別途チェック** — SUUMO等に載らないので、[UR公式](https://www.ur-net.go.jp/chintai/)で直接探す。今回のケースでは最有力候補
5. **内見・申込** — 気に入った物件は複数社に問い合わせて初期費用を比較。キャッシュバックサイトからは問い合わせない
