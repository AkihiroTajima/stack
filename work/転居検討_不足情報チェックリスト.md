## 1. 現状の把握で埋めるべき穴

- [ ] **固定費「生活費 40,000円/月」の正体** — 実家に入れている生活費か、自分の食費・雑費か。転居で**消えるのか継続するのか**で年間48万の差
- [ ] **実家在住中に親が負担している費用の実額** — 電気・ガス・水道・ネット・食材費・日用品。転居後は自分の支出に付け替わる
- [ ] **「引き出し」月平均28,571円の使途** — 年34万。現金支出の中身が不明なままだと転居後の予算が組めない
- [ ] **「生活用品」86,296円/月の内訳分解** — 実際には靴33,110円、リュック39,929円、ランニング用品など単発の買物が混在。**恒常費と一時費の切り分け**が必要
- [ ] **緊急予備資金の方針** — 現預金822万のうち、いくらを「動かせない金」として確保するか

## 2. 転居後に新規発生するランニングコスト

- [ ] 家賃（管理費・共益費込み）
- [ ] 光熱費（電気・ガス・水道）— 一人暮らしなら 8,000〜15,000円/月が目安だが、地域・オール電化かで変動
- [ ] 自宅インターネット回線 — 現在は「キャリア通信料金 1,012円」のみで固定回線なし
- [ ] 火災保険料（年額）
- [ ] 更新料（2年ごと・家賃1ヶ月分が一般的）
- [ ] 駐車場・駐輪場代の要否
- [ ] NHK受信料
- [ ] 通勤定期代 — 会社支給か自己負担か、支給上限額はいくらか
- [ ] 食費の増加分 — 現在44,313円/月は実家の食事があった上での外食・間食。自炊前提でも増加が見込まれる

## 3. 転居時の一時費用（初期費用）

- [ ] 敷金・礼金・仲介手数料・前家賃・保証会社利用料 — 合計で**家賃の4〜6ヶ月分**が目安
- [ ] 引越業者費用（時期・距離・荷量で大きく変動、繁忙期は割高）
- [ ] 家具・家電の購入費 — 冷蔵庫・洗濯機・電子レンジ・カーテン・寝具・照明。実家から持ち出せるものの棚卸しが先
- [ ] 鍵交換代・室内清掃費

## 4. 収入側の前提

- [ ] **賞与の再現性** — 6月65万・12月50万は確定的か、業績連動か。連動なら悲観ケースの数字が必要
- [ ] **昇給見込み** — 今後1年の手取りの推移
- [ ] **転職の可能性** — 「ITエンジニアの転職学」等の書籍購入あり。転職するなら収入も勤務地も前提が変わるため、**転居より先に確定させるべき順序の問題**
- [ ] 住民税・社会保険料の扱い — 手取り25万が控除後か、独立で扶養関係が変わるか

## 5. 物件条件（金額を確定させるために必要）

- [ ] 勤務地と許容通勤時間 → 検討エリアの確定
- [ ] 間取り・広さの下限（1K / 1DK / 1LDK）
- [ ] 必須設備（バス・トイレ別、独立洗面、宅配ボックス等）
- [ ] 上記条件での**エリア別家賃相場**の実地調査（SUUMO等で3〜5件の実例収集）

## 6. 先に決めるべき判断基準

- [ ] **投資積立30,000円/月を転居後も維持するか** — 維持前提なら払える家賃の上限が下がる
- [ ] **目標2,000万円の達成期限** — 期限がなければ「転居して達成が何年遅れるか」を評価できない
- [ ] **貯蓄率の下限ライン** — 現在43%。転居後に何%を割ったら「支出過大」と判断するか
- [ ] **娯楽費81,546円/月の扱い** — 家賃捻出のため削るのか、削らない前提で家賃上限を計算するのか
