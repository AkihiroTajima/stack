## 条件1：平均月収額が基準月収額以上

### 基準月収額（単身者の場合）

| 家賃額 | 基準月収額 |
|---|---|
| 62,500円未満 | 家賃額の4倍 |
| **62,500円以上 20万円未満** | **25万円（固定額）** |
| 20万円以上 | 40万円（固定額） |

検討中の家賃6〜7万円は2段目にあたるため、**必要なのは「平均月収額25万円」の固定ライン**。

### 「平均月収額」の定義がポイント

> 給与収入や事業所得など、将来も継続すると認められるもので、**原則として過去1年間の合計額を12で割った額**。いずれも**課税対象になっているもの**で、かつ証明できるものに限る。

課税対象＝**額面（税込）**。手取りではありません。証明は**前年分の源泉徴収票＋本年度の課税証明書（または住民税決定通知書）**。

### 判定

`mit-2026.xlsx` の「収入 250,000円/月」が手取りか額面かで話が変わります。

- **手取りである場合（家計簿の性質上こちらの可能性が高い）**
  年間手取り 4,197,500円から逆算すると額面年収はおよそ520〜560万円。**平均月収額は約43〜47万円**となり、基準25万円を大幅に上回る → **余裕でクリア**
- **額面である場合**
  賞与込みの年収は約419.8万円 → 平均月収額は約35万円。これも基準を上回る → **クリア**

**どちらであっても条件1は満たします。** ただし賞与が業績連動で大きく落ちた年の源泉徴収票で審査を受ける場合は数字が下がるため、直近の源泉徴収票の「支払金額」を実際に確認しておくこと。

### 代替手段①：貯蓄基準制度

月収基準を満たさなくても、**貯蓄額が家賃の100倍以上**あれば代替できます。

- 対象は「金融機関の預貯金の合計額」で、**残高は円預金**とされている
- → **投資評価額 1,078,906円は算入できない可能性が高い**。現預金 **8,224,146円** で判定する

| 家賃 | 必要貯蓄額 | 判定 |
|---|---|---|
| 60,000 | 600万 | ✅ クリア |
| 70,000 | 700万 | ✅ クリア |
| 80,000 | 800万 | ✅ クリア（余裕は22万） |
| **82,241** | 822万 | **上限ライン** |
| 100,000 | 1,000万 | ❌ **不足** |

**貯蓄基準だけで通せるのは家賃82,241円まで。** 10万円の物件は収入基準で通す必要があります。

### 代替手段②：家賃等の一時払い制度

1〜10年分の家賃・共益費を前払いすると、**収入要件が問われず、期間に応じて家賃が割引**されます。

- 現預金822万があるので実行は可能（家賃7万×1年＝84万）
- ただし**やむを得ない事情を除き途中解約できない**
- 流動性を大きく削るため、収入基準・貯蓄基準の両方をクリアしている今回のケースでは**使う必要がない**。割引率次第で検討する程度

## 条件2：日本国籍、または所定の在留資格

あわせて「継続して自ら居住するための住宅を必要とする方」であること。セカンドハウス目的は不可。今回は独立目的なので該当します。

## 条件3：単身者もしくは現に同居し、または同居しようとする親族のある方

**単身者は明示的に対象。クリア。**

## 条件4：入居開始可能日から1か月以内に入居でき、円満な共同生活を営める方

**ここが実務上の制約になります。** URは抽選なし・先着順ですが、契約後1か月以内の入居が求められるため、「良い物件が出たら1か月で動ける状態」を作っておく必要があります。転職を検討している場合、その時期と衝突しないか確認してください。

## 条件5：申込者本人を含めた同居世帯全員が暴力団員などでないこと

契約時に「反社会的勢力ではないこと等に関する表明確約書」に署名。クリア。

## 注意事項（資格とは別枠）

- UR都市機構に対する**未払い金がないこと**
- 過去にUR住宅（旧公団住宅含む）で家賃滞納・近隣迷惑行為・動物飼育などの契約違反、虚偽申告がないこと

UR居住歴がなければ問題ありません。

## 必要書類チェックリスト

### 本申込時

- [ ] **賃貸住宅入居申込書**（UR指定様式・営業センターで記入）
- [ ] **住民票の写し**
  - 3か月以内に取得した原本
  - **マイナンバーの記載がないもの**
  - **続柄が記載されたもの**（申請時に「続柄が必要」と明記しないと省略される）
- [ ] **前年分の源泉徴収票**
  - 原本（社印押印済み、または電子交付されたもの）
  - **マイナンバーの記載がないもの**
  - ※採用後1年未満の場合はUR指定様式の収入証明書＋社員証の写し
- [ ] **本年度の課税証明書** または **本年度の住民税決定通知書**
- [ ] （貯蓄基準を使う場合）**残高証明書**
  - **円預金のみ**
  - **金融機関での発行後7日以内**のもの → タイミング管理が必要

### 契約時

- [ ] 賃貸借契約書（署名押印）
- [ ] **敷金（月額家賃の2か月分）** ※事前に払込票で金融機関にて支払い
- [ ] **入居月の日割り家賃および共益費** ※同上
- [ ] **実印および印鑑証明書（3か月以内に取得）**
- [ ] **本人確認書類**（マイナンバーカード、運転免許証、または現住所記載のパスポート）
- [ ] 契約はUR営業センター等に本人が出向いて締結

> 写真付き本人確認書類を提示してコピーを提出する場合、**印鑑証明書の提出は不要**になります。

## 🔴 先に潰しておくべき2点

### 1. 本人確認書類

**運転免許証を持っていないため、マイナンバーカードか現住所記載のパスポートが必要です。** どちらも手元にない場合、マイナンバーカードの発行に**申請から1か月前後**かかります。条件4の「1か月以内に入居」と組み合わさると、物件を見つけてから慌てることになるので、**探し始める前に取得を済ませておくべき**です。

### 2. 実印と印鑑登録

契約時に実印と印鑑証明書（3か月以内）が要ります。写真付き本人確認書類のコピー提出で代替できる可能性はありますが、**印鑑登録をしていない場合は市区町村での登録手続きが必要**です。こちらは即日〜数日で完了します。

### 補足：源泉徴収票の保管

前年分（2025年分）の源泉徴収票の原本が必要です。手元になければ勤務先に再発行を依頼することになるため、**今のうちに所在を確認**しておくと安全です。

## 結論

**資格条件（1〜5）はすべて満たせる見込みです。** 収入基準・貯蓄基準のどちらでも通り、家賃82,241円までは貯蓄基準単独でもクリアできます。前回試算した家賃6〜7万円のレンジは余裕をもって範囲内です。

**障害になるのは書類側、特に本人確認書類です。** 運転免許証がない以上、マイナンバーカードかパスポートの取得が実質的な前提条件になります。物件探しより先にこれを片付けてください。
