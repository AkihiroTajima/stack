
# 数学における発見

ピタゴラスの定理
`a^2 + b^2 = c^2`

- 空間を数学的に分析する基礎
- 幾何法則に対する「証明」という手続きの先駆け
- 無理数の発見

三角法

- 拡張されたピタゴラスの定理
  - ピタゴラスの定理は直角三角形の2辺の長さがわかっている時の残りの辺の長さを求める公式
  - 直角三角形以外に拡張するには、正射影という考え方を導入する
- 正射影
  - ある線分上の各点から別の直線上へ下した垂線の足からつくられる線分
  - 影に相当する
  - 線分と正射影の長さは比例関係にあり、なす角の変化に伴い変化する。
  - 例えば、頂点Bから線分ACに垂線を下ろし、その交点をHとすると、ピタゴラスの定理を利用して以下の等式を得る
    - `c^2 = a^2 + b^2 -2bCH`
  - ここで、長さ1の線分をそれと角度θをなす直線L上に正射影した線分の長さをcosθという記号であらわす。
  - すると、`CH = acosθ`から`c^2 = a^2 + b^2 -2abcosθ` が得られ、これは余弦定理と呼ばれる。

負の数

- 余弦定理を鈍角に拡張する場合、その値が負の数をとるように整合させる。
- 上の拡張によって、現代のcosθの定義が理解できる
  - 単位円上の点(1, 0)から出発し、円周上を1度/sで反時計回りに移動する点Pのx座標

座標平面

-  平面上にある点Pからx軸とy軸に垂線を下ろし、それぞれの交点の値をa, bとしたとき、点Pの座標を数字のペア(a, b)と表す。
-  この表現により、ある方程式の解とそれらを打点した図形は、双方に対応する。

代数幾何
K次の不定方程式の解の集合が描く図形を総合的に研究する分野

- 円の方程式をピタゴラスの定理から求めることができる
- 幾何的な性質を代数計算に対応させて処理することができる
  - 例えば、円と直線の交点を計算で求められる 

負の数の解釈

- 負数を含んだ計算を「方向算」にみなす。
- 1次のベクトルといえる。

ベクトルは数の高次元化

- 並列計算の数学的表現に用いられる（ベクトルの加減）
- ベクトル同士のの掛け算
  - 内積 `(a, b)・(c, d) = ac + bd`
  - `ac + bd = 0` のとき、2つのベクトルは直行する
  - `ac + bd =! 0` のとき、内積の値は各ベクトルの移動距離に「間の角のコサイン」を掛けたもの。
    - 「間の角のコサイン」は正射影の倍率を表す
    - `ac + bd = |a||b|cosθ = |a|(ベクトルbのベクトルa上への正射影の符号付き長さ)`

## 関数の極値を求める方法
無限小の線分の傾きを求める
- 式f(x)をある点Pを原点とした座標系(Δx, Δy)で表現する
- 2乗の項を無視する

上の操作によって、点P日近づくほど誤差が小さくなる近似式を得る。
誤差をΔxで割った値「誤差率」を考え、これをΔx→0に飛ばすと、線分の傾きを得る

# 連立方程式
クラメールの公式の意味
- ax + cy = p
- bx + dy = q
に対して
- x = (dp-cq)/(ad-bc)
- y = (aq-dp)/(ab-bc)

補助問題：(ad-bc)の意味
- ベクトル(a, b)とベクトル(c, d)を2辺とする平行四辺形の符号付面積
  - 行列式とも呼ばれる、外積で掛け算の一種
- 行列式 det((a, b), (c, d)) = ad-bc
行列式を用いて
- x = det((p, q), (c, d))/det((a, b), (c, d))
  - ベクトル(a, b)の延長率
- y = det((a, b), (p, q))/det((a, b), (c, d))
  - ベクトル(c、d)の延長率

クラメールの公式は、連立方程式の解を図形的な量でとらえる表現
- ベクトル(a, b)をx倍、ベクトル(c、d)をy倍して(p, q)を得る方法

## 微分と積分
「面積和」を「線分の長さ」にすり替える
 
- 階段型図形の面積の和 f(x)(x1-x0) =f(x)Δx
  - p... x0からx1にある数
  - x1-x0... 区間の長さ
- F(x) の増分 F'(x)Δx
  - ここで、f(x) は F(x)の導関数

## 曲線で囲まれた図形の面積

定義：リーマン和が近づく極限、定積分とも表現される <br>
リーマン和の定義：Sn = Σf(Pk)(xk-xk-1)
- xk... kは添え字でxk-1はk-1番目のxを表す。xkはf(x)をn個に区切った時の区切り
- Pk... f(x)をn個に区切った時、区間ごとの任意の値

リーマンの定理：関数f(x)が連続ならば、定積分は存在し、分割点xkや代表点Pkの取り方の無関係に決まる
