## 第一章 統計学の基礎

近代統計学... 現象の法則性を求めるもの
 - 記述統計学
 - 統計的推論

統計学の歴史
 - 全数調査... ある集団の法則性を知るためには、全体を調べねばならないという考え方
 - 回帰、相関... 全体として平均に退化していくこと
 - 分布... 個々のばらつきは論理的確率的分布が背後にある

データ
 - 量的・質的
   - 量的データ... 定量的な値で与えられるもの
   - 質的データ... 数値として観測出来ず、あるカテゴリーに属していることだけがわかるデータ
 - 統計資料... 統計処理を施した後の調査結果（↔原データ）
   - 第一義統計... あらかじめ統計資料を作成する目的で調査し、その結果を集計したもの
   - 第二義統計... 統計資料用でない資料からつくられた統計資料

統計プロセス
 - 分析対象(仮説)の決定
 - データの収集（実験や調査を含む）
 - 統計分析を行う

## 第二章 一次元のデータ

記述統計学... 
 - 集団としての特徴を記述するために、観測対象となった各個体について、観測し得られたデータを整理・要約する方法

ヒストグラム
 - 階級... 観測値の取りうる値を分けるもの
 - 度数... それぞれの階級で観測値がいくつあるか
 - 階級値... 階級を代表する値、一般に階級の上限と下限の中間値がとられる
 - 相対度数... 度数が全体のうちにとる割合
 - 層別... 峰が2つ以上ある場合、性質の異なるデータが混じり合っていることが多く、グループ分けによって単峰型に分けられることが多い（身長の分布を性別で層別化する）
 - スタージェスの公式... 階級数kの目安
   - k = 1+log2(n) nは観測値の数
     - = 1+log10(n)/log10(2)

測定の尺度
 - 名義尺度... ある個体が他とは異なるか同一化、という判断の基準
 - 順序尺度... ある個体が他よりも大きい、良い、多い...といえる比較判断の基準
 - 感覚尺度... ある個体は他よりもある単位によって～だけ多いといえる判断の基準
 - 比尺度... ある個体は他よりある単位によって～倍だけ多いといえる判断の基準

代表値... 分布を代表する値
 - 平均... データの重心。算術平均、幾何平均、調和平均などが一般的
 - 中央値... 観測値を並べ替えたときの中央の値、四分位点はこれを拡張したもので、並べ替えたデータを4等分する3点
 - 最頻値... 分布の峰に対応する値
 - ミッドレンジ... (最大値-最小値)/2

散らばりの尺度
 - レンジ... 最大値-最小値
 - 四分位偏差... (Q3-Q1)/2
 - 偏差... 各観測値と平均との隔たり。平均偏差、標準偏差など
 - 変動係数... 標準偏差/平均。観測値の規模が変化したときの比較に利用できる
 - 標準得点... 各観測地xを(x-平均)/標準偏差、と一次変換したもの。異なるデータでの比較を可能にする（国語の点数と数学の点数）

## 第三章 二次元のデータ

二次元のデータ... 2変数x, yを観測して得る、n組のデータ。n変数の場合は多次元データとも呼ぶ。(n>1) <br>
相関... xとyの間に区別を設けず対等に相互関係を見る方法。<br>
回帰... xからy(またはその逆)が決定される様子や程度を扱う <br>

散布図と分割表
 - 散布図
   - (x, y)を横軸と縦軸にとり、平面上にプロットしたもの
   - x, yは量的データ
   - 二つの変数の間に、直線関係に近い傾向がみられるときに「相関関係がある」という。
 - 分割表
   - 縦方向の項目を表側、横方向の項目を表頭と呼ぶ
   - 表側と表頭が交差する細目のマス目に対応する度数を書き込んだものを分割表またはクロス表と呼ぶ。
   - 一般に、縦横にそれぞれ合計を記入する
   - x, yは質的データ
   - 分割表の分析では、相対度数を見る。相対度数は表側か表頭ごとに計算されたものを用いるのが一般。

相関係数... 相関の度合いを示す指標
 - ピアソンの積率相関係数が代表的
 - 相関関係が高い場合でも、因果関係がない場合がある。
   - みかけ上の相関。xとyの相関があるとき、第三の変数をはさんで相関関係が観測される場合、偏相関係数を用いた方が良い。
 - 相関関係が期待されるが観測できない場合、性格が異なるいくつかの部分集団を含んでいることがある。この場合、層別によって各グループでの相関が現れることがある。
 - 順位相関係数.. 質的データにおいて、順位間の相関を示す指標
 - 時系列と自己相関
   - 時系列... データが時間的に観測されたもの
   - 自己相関係数... 時系列をずらして(x1, x2), (x2, x3)...としたときの相関係数。ずらす間隔を「遅れ」と呼び、1以外の値も検討する価値がある

直線および平面のあてはめ
 - 最小二乗法... 直線`y = ax + b`から予想されるyの値と現実の値`yi`との差の二乗を最小にするaとbを求める手法
 - 決定係数... 相関係数の二乗の値。独立変数xが従属変数yを決定する強弱の度合いを示す
 - 重回帰... 説明変数xが二つ以上の場合の回帰

## 第四章 確率

 - 確率論... ランダムネスの法則を扱う数学理論
 - ランダムネス... 何が次に起こるか確定的に予想できないこと

標本空間と事象
 - 標本空間... 可能な結果 (標本点) の全体の集合
 - 事象... 標本空間の部分集合として定義されるもの。起こりうる事柄を指す。
 - 根源事象... ただ一つの標本点からなり、分解できない事象 (↔複合事象)
 - 事象の演算
   - 和事象... 事象A, Bの二つのうち少なくとも一つが起こるという事象
   - 積事象... 事象A, Bが同時に興るという事象

確率の定義... 事象の興りやすさを定量的に示すもの。事象Aに対してP(A)と表す。
 - ラプラスの定義... `P(A) = R/N`
   - R = 試行のうち事象Aが起こるような根源事象の数
   - N = 試行のうちすべての根源事象の数
 - 頻度による確立の定義... `P(A) = α`
   - αの定義、`nA/n → α (n → ∞)`
   - n = 事象Aを生み得る実験の試行回数
   - nA = n回中、事象Aが起きた回数
 - 公理主義的定義
   - すべての事象Aに対して`0≦P(A)≦1`
   - `P(Ω) = 1` (Ωは全事象)
   - 互いに排反な事象A1, A2, A3...に対して、`P(A1∨A2∨A3∨...) = P(A1) + P(A2) + P(A3) + ...`

## 第五章 確率変数
 - 確率変数
   - 確率的に動く量
   - 各値に対して、それぞれ確率が与えられている変数
   - 確率変数Xに対して、`X=x`の確率をpとおくと、`P(X=x) = p`と表現する
 - 確率分布... 確率変数Xの値の確率`P(X=xk) = f(xk)`としたときのfを確率分布と呼ぶ。

 - 確率分布の代表値
   - 期待値
     - 離散型について`E(X) = Σxf(x)`
     - 連続型について`E(X) = ∫xf(x)dx`
   - 分散
     - 離散型について`V(X) = Σ(x-μ)*(x-μ)f(x)` ここで、μは期待値のこと
     - 連続型について`V(X) = ∫(x-μ)*(x-μ)f(x)dx`

 - モーメントとモーメント母関数
   - モーメント... 確率分布の形を決定する量。`μr = E(Xのr乗)`をr次のモーメントと呼ぶ。
   - モーメント母関数... すべての次数のモーメントを生成する関数。`Mx(t) = E(eのtX乗)`と定義する。

## 第六章 確率分布

離散型
 - 超幾何分布
   - 2種類のものが全部でN個ある中からn個選んだときの確率分布。
   - 2種類のA, BからなるN個のものがあり、それぞれの個数はM, N-Mとする。Aがx個、Bがn-x個である確率は、`f(x) = MCx·(N-M)C(n-x)/NCn` ただし`x = MAX(0, n-(N-M)), MIN(n, M)
 - 二項分布
   - 2種類の可能な結果を生じる試行の結果の確率分布
   - それぞれの結果(SとF)が生じる確率をp, 1-pとする。これをn回繰り返した際にSがx回、Fがn-x回起きる確率は、`f(x) =nCx·(pのx乗)((1-p)のx乗)`
 - ポアソン分布
   - 二項分布において、起きる確率が極めて小さい現象を大量に観察する場合の確率分布。
   - `f(x) = exp(-λ)(λのx乗)/x!` ただしλは変数
 - 幾何分布
   - 2種類の現象のうち、片方が生じるまでの試行回数xの確率分布。
   - `f(x) = pqのx乗` ただしp, qはそれぞれ2種類の現象が起きる確率
 - 負の二項分布
   - k回目の成功を得るまでの失敗回数をxとしたときの確率分布。
   - `f(x) = (k+x-1)Cx(pのk乗)(qのx乗)` ただしp, qはそれぞれ2種類の現象が起きる確率
 - 一様分布
   - `f(x) = 1/N`

連続型
 - 正規分布
   - ありふれた値を測定した際の誤差を含めた確率分布としてよくあらわれる。
   - `f(x) = (1/(2πσの1/2乗)exp(-((x-μ)の2乗)/(2σのx乗))`
 -  指数分布
    -  連続的な待ち時間分布の性質を持つ
    -  `f(x) = λ(eの-λx乗)`
 -  ガンマ分布
    -  指数分布を一般化したもの
    -  `f(x) = {(λのx乗)/Γ(α)}(xのα-1乗)exp(-λx)`
 -  対数正規分布
    -  所得のように、低いほうは一定限度があるが、高いほうには明確な限度がない、といった場合に適切な確率分布。
 -  パレート分布
    -  対数正規分布に対し、高額所得者の所得分布。ある値以上で存在し、そこから急に減少する
 -  ワイブル分布
    -  故障率に偶発を加味する際は指数分布に従う。ここに劣化による故障率の増加と、初期故障による故障率の現象を考慮した際の確率分布。

## 第七章 多次元の確率分布
 - 同時確率分布 `P(X=x, Y=y) = f(x, y)`
   - `f(x, y) = (xとなる事象の数)/全事象数 + (yとなる事象の数)/全事象数`
   - f(x, y)は同時確率密度関数と呼ぶ
   - f(x, y)から、xかyの片方を固定することで、事象X, Yについて、それぞれ単独の確率分布が求められる。これを周辺確率分布と呼ぶ。

 - 共分散と相関係数
   - 共分散... 事象X, Yがそれぞれの平均から、互いに関連しながらばらつく程度を表す。
     - `Cov(X, Y) = E{(X-μx)(Y-μy)}`
   - 相関係数... 共分散が表すX, Yの関係の程度を表す。
     - `ρXY = Cov(X, Y)/√V(X)√V(Y)` 

## 第八章 標本分布

用語
 - 記述統計学... 分析対象の分布を要約、整理する
 - 統計的推測... 母集団の一部を抽出し、母集団について推測を行う
 - 母集団... 知りたいと思う集団全体
 - 標本... 母集団から分析のために選び出された要素

母集団分布の母数
 - 母集団分布が事前に与えられている場合、いくつかの定数を決めることで、母集団分布を得ることができる
 - 母集団分布を決定する定数を母数 (パラメータ)という
 - 母集団分ぷがわかっている場合を「パラメトリック」。そうでない場合を「ノン・パラメトリック」という
 - ノン・パラメトリックの分析では、モーメントから分析を行う

統計量... 標本を要約し、母数の推測に用いられるもの
 - 標本の平均、分散、中央値、最大値、最小値、相関係数など
 - 統計量の確率分布を標本分布という

| ポアソン分布 Po(λ)      | Po(nλ)             | 
| 正規分布 N(μ, ρの二乗) | N(nμ, n(ρの二乗)) |
