# Critical Thinker Academy: Learn to Think Like a Philosopher

## クリティカルシンキング
 - 目的：
   - 簡単に説得されない術を学ぶ
   - 人間の知的活動の質を向上させる
 - 基本要素：
   - 論理 logic
   - 論証 argumentation
   - 修辞学 rhetoric
   - 知識 background knowredge
   - 価値観 attitude and value

## 前提と結論
論理と論証の違いについて
 - 「論理」では、前提から結論を導くことができるかに着目する
 - 「論証」では、前提が妥当かどうかに着目する
   - 妥当性を論証するためには関連する知識と他者の視点で考える態度が必要になる

## バイアス
偏った見方、素早い判断が生死を分ける時代の名残という説がある
 - 「認知バイアス」
   - 一度決断すると、その内容を否定する情報を受け付けなくなる
   - ある情報が、直接関係ないとわかっていても、直前に提示されるとヒントとして作用する
 - 「感情バイアス」
   - 不快な情報を無視する

そのほかにもたくさん存在する。クリティカルシンキングの実践上で主な障害として意識されている。

## Tribalism
 - 集団に属することによる諸問題
   - ほかの集団に対して、否定的な態度が求められることがある。しかし、この原因の多くは集団形成にはない。
   - 二極化が進み、明確な対立が存在すると、攻撃的な態度がよく見られるようになる
   - 集団の所有する知識（集合知）は、個人がよく理解していると錯覚させることがあるが、実際にテストしてみると驚くほど理解していないことがわかる

## 科学用語
fact, low, theory, hypothesisに対して、「根拠の量」による比較と、「言葉の持つ意味」による比較を明確にする。
 - 根拠の量 Epistemically loaded
   - fact: 疑う余地のない事実、信念を表す
   - low: 繰り返し確認される事象
   - theory as Uo-Player: 科学的手法で十分に検証された理論
   - theory as Down-Player: 理屈
   - hypothesis: テストが十分でない推測
 - 言葉の持つ意味 Epistemically Neutral
   - fact: 真であるといこと
   - low: 一般化する、予測を可能にする、物理的に可能なことと必然を区別するといった役割を持つ
   - theory: 自然法則を説明する主張、科学では論理を立てるツールとして用いられている 
   - hypothesis: テストする対象 (形式的には IF H THEN O)

Model
 - 世界のある特徴を推測するための抽象化された概念
 - 論理の応用例としてよく用いられる

論理の解釈
 - 論理が真であるならば、何が言えるのか
 - 論理が真でも、言えないことは何か、つまり、論理が無視していることは何かに着目する

## 陰謀論
陰謀
 - 集団による秘密の悪事

クリティカルシンキングとの関係
 - 陰謀論を受け入れる十分な根拠はあるか
 - 歌買うという態度においてクリティカルシンキングと陰謀論は共通する

反証可能性
 - 陰謀論を支持する人は、反証できないことを根拠とする場合がある

陰謀論に対する態度
 - 大規模な陰謀の実現は現実的でないが、すべての陰謀論を理由なしに否定するのはクリティカルシンキングの態度と一致しない

## Argument 論証
定義
 - 主張や文の集合
 - 主張の一つは結論で、残りは前提と呼ばれる
 - 前提は結論に対する理由として存在する

Standard Form
 - 前提と結論をそれぞれ一行に書き表し、最終的な結論がどのように導かれたかわかりやすいように整えられた形式
 - 例）
   - 1. 前提(1)
   - 2. 前提(2)
   - ...
   - therefore ゆえに、結論

Claim 主張
 - 主張は真か偽である文章、真偽の両方を取ることはない
 - claim, statement, propositionといった呼び名を持つ
 - 無矛盾律... 主張が同時に真と偽であることを許さない

よい論証の条件
1. (Truth Condition)すべての前提が真及び尤もである 
2. (Logic Condition)結論は前提から導かれる。論証が有効もしくは強いと表現される

valid argument 有効な論証
 - すべての前提が真ならば、結論が偽になりえない

strong argment 強い論証
 - すべての前提が真ならば、結論が真である可能性が十分高い

演繹的、帰納的論証
 - 演繹的
   - 有効であるように意図した論証
   - 科学的には、一般的な前提から特殊な結論を導くこと
 - 帰納的
   - 強い論証を導くことを意識したもの
   - 科学的には特殊な前提から一般的な結論を導くこと

## 命題理論
Basic compound claims
 - and... すべて真
 - or... 少なくとも一つ真
 - IF ANTECEDENT THEN CONSEQUENT... ANTECEDENTが真ならばCONSEQUENTも真。NOT(IF A THEN B) = A AND NOT(B)
 - NOT(A)... Aは偽

否定と反対
 - 否定 contradictory... それ以外のすべて真偽が一致しない
 - 反対 contrary... それ以外の一つ、同時に真にならないが同時に偽にはなる
 - 例）命題「このボールは白い」
   - 否定「このボールは白くない」
   - 反対「このボールは黒い」

矛盾
 - A and NOT(A)

一貫性
 - すべての主張が同時に真となりえる命題集合

必要十分
 - A is sufficient for B = IF A THEN B
 - A is necessary for B  = IF B THEN A

Categorical Claims
 - All A are B  = NOT(Some A are B)
 - Some A are b = NOT(No A are B)
 - No A are B

## 非形式的な誤謬
誤謬とは
 - 一般に悪いとされる論証
 - 論証をStanderd Formにしてから評価するとよい

AdHominem
 - 論証ではなく論者を攻撃すること
 - 論者の性質を根拠とした否定や論者の持つ関係から弱い推測を行うなどがある

Appeal to Hypocrisy
 - お前だって論法
 - 論証と論者の信念や行動は独立しているので、それらを否定材料にすることは不適当

Appeal to Popluar Belief/Authority
 - 他者の評価を前提に取り入れるもの
 - 多くの人や権威の意見・行動が結論を導くための前提として適当とは限らない

False Dilemma (誤った二分法)
1. A or B
2. NOT(A)
3. Therefour B

 - とするとき、A or B or C or D...などがある場合、上の論証は無効

Slippery Slope
 - 弱い推論の連続から望ましくない結論を導くこと
 - 例）
   - 「まじめに勉強しないと、将来は一生パートで安い給料しか稼げない」
     - 前提1. まじめに勉強すれば、いい大学に入学できる
     - 前提2. いい大学に入学できれば、いい会社に就職できる
     - 前提3. いい会社に就職できれば、いい給料をもらえる
     - 前提4. 良い給料をもらえない
     - 結論 . まじめに勉強してない

Straw Man
 - 相手の主張を都合よくゆがめて解釈し、反論すること

Red Herring
 - 主要な問題への集中を阻害する要素
 - 関連の弱い事柄を持ち出して反論するなどがある

Begging the Question
 - 結論の言い換えを前提に用いること。
 - 循環論法などに陥る
 - 広義的には、前提の尤もらしさが結論より低いことで、結論の尤もらしさを論証の前後で変化させることができないことを指す


## 偶然に関する誤謬
 - ある事象が偶然かどうか判断するのは、一般に困難なので、統計学などを用いて考えるべき
   - 例）
     - 誕生日のパラドックス (https://mathtrain.jp/birthday)
     - 予想を的中させるのではなく、予想が的中する対象を選択することができるかどうか
       - ダーツの中心を狙うのは難しいが、当たった場所を中心とすれば必中

## ギャンブルとバイアス
 - フェアな賭け
   - 出る目の確立の偏りがない
   - 出る目の確立がそれぞれに独立している
 - 予算の大きい方がいずれ勝つ
   - 起こりうるすべて場合がいずれ起こる、ならば、負けが連続するとき、予算の小さい方が負けやすい
 - まったくの偶然に対しても、意思が働いていると感じるバイアス
   - よい結果ならコントロールしていると感じる
   - 悪い結果ならコントロールされていると感じる

## 少数サンプリングによる誤謬
 - 少ないサンプルは極端な値が出やすい
   - 白黒の玉が均等に入った箱からいくつか取り出す場合
     - 2個取り出すなら、白だけが取り出される確率は0.3
     - 4個取り出すなら、白だけが取り出される確率は0.2

## 論文・エッセイの書き方
 - 基本構造
   - 導入部分
   - 主文
     - 主論 (結論とそれを導く前提)
     - 主論に対する反論
     - 反論に対する反論
   - 結論

 - イントロの役割
   - 文章のテーマ、題材にする問題を伝える
   - 何が問題なのか、その背景を伝える
   - どういった結論を出すのか伝える
   - 長い文章の場合、そのアウトラインを前もって知らせる
 - 結論の役割
   - まとめ（簡潔な主論や結論）を述べる
   - コメントや、今後の課題点を述べる
