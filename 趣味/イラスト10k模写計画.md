## 達成目標（生涯目標）
- 10,000枚のイラスト模写を完了する

## 進め方

累計枚数だけを数える。連続日数は数えない。休んでも減らない。

**カウント条件：5分以上手を動かしたら1枚。** 完成度は問わない。線1本でも「描き始めた」なら1枚。

## 10の段階

累計枚数が節目に届いたら次の段階へ進む。段階が変わると、やることの重心が移る。

| 段階 | 累計 | この段階でやること |
| --- | --- | --- |
| 1 | 〜100 | 好きな絵をそのまま模写。上手い下手は評価しない。まず手が動く状態を作る |
| 2 | 〜300 | 部分模写を解禁。顔だけ、手だけ、服のシワだけ。苦手なパーツを狙い撃つ |
| 3 | 〜600 | 模写のあとに「なぜこの線か」を1行メモ。見え方の解像度を上げる |
| 4 | 〜1,000 | 模写を1箇所だけ改変する（服・角度・表情）。自分の判断を混ぜ始める |
| 5 | 〜1,600 | 複数の元絵を合成して1枚にする。構図を自分で決める |
| 6 | 〜2,500 | 模写を別アングルで描き直す。モルフォと併走して立体を掴む |
| 7 | 〜3,600 | 光・影・背景を自分で足す。画面の空気を作る |
| 8 | 〜5,000 | シチュエーション先行で描く。ネタ帳から起こす |
| 9 | 〜7,000 | オリジナルが主食。模写は補給として使う |
| 10 | 〜10,000 | 自分で決める |

序盤は1枚の重みが大きい。100枚は1日3枚なら1ヶ月ちょっとで届く。

## 節目の1枚（この計画の本体）

**段階が変わるたびに、オリジナルを1枚完成させて外に出す。**

- 題材は、その段階の模写のうち一番「描いてて楽しかったもの」から選ぶ
- 完成の定義は自分で下げていい。線画だけ、ラフだけでも可。**出すことが条件**
- 出し先：SNS / 手元のログ / 誰か1人に見せる、のどれでもいい

## 気分が乗らない日の選択肢

どれも1枚としてカウントする。

- **模写する気がない** → 好きな絵を5分眺めて、いいと思った箇所を1行メモ
- **時間がない** → 顔だけ / 手だけ / 服のシワだけ
- **何を描くか決まらない** → 模写対象リストを適当に開いて、最初に目に入った絵
- **上手く描けなくて嫌** → わざと崩す。デフォルメ、落書き化
- **調子がいい** → 模写 → そのまま1箇所改変してオリジナル化

## ルール

1. 累計だけ数える。連続記録は追わない
2. 1日の上限なし。乗った日は10枚描いていい
3. 必達ノルマなし。「1日3枚」は目安であって義務ではない
4. つまらなくなったら段階を飛ばしていい。段階2でオリジナルを描きたくなったら描く
