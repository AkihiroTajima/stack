## 目的
- 新しいことが起きている業界や分野を調査する
- 人の役に立つ、需要のある仕事を探す

## 手段
- 四季報をもとに情報をまとめる
- Claudeを用いた情報収集を行う

## Claude調査結果
### 1. ロボティクス / 身体を持ったAI(Embodied AI)

いま最も勢いがある領域です。知能はもう画面の中だけのものではなく、身体化され、自律的に、現実世界の問題を解き始めているとDeloitteは表現しています。具体的な数字でも、2024年に産業用ロボットが54.2万台設置され、10年前の倍以上、ヒューマノイドロボット市場は2025〜2030年に年率40%成長で2030年に約180億ドルへと見込まれています。 [Deloitte Insights + 2](https://www.deloitte.com/us/en/insights/topics/technology-management/tech-trends.html)

なぜ効くか:ここの核心は「現実世界で動く知能をどう作るか」という、まだ誰も完全に答えを持っていない問題群です。あなたの言う「業務支援」とは対極の、自分で問題を立てる余地が大きい。そしてロボットが実際に荷を運ぶ・組み立てるという物理的成果が出るので、役立っている感覚は得やすい。ソフト側のスキル(制御、シミュレーション、知覚、強化学習、システム統合)がそのまま武器になります。

### 2. Techbio / 計算生物学(AI × バイオ)

ソフトエンジニアにとって参入余地が一気に広がっている領域です。2025年のバイオテックのベンチャー資金は約380億ドルで前年比28%増と資金も戻っており、AI、機械学習、創薬・診断のためのソフトウェア技術者への構造的な採用増が起きています。データパイプライン、モデリング、シミュレーションといったスキルが、生物学のドメイン知識と組み合わさると希少価値になります。 [Qubit Capital](https://qubit.capital/blog/high-growth-startup-sectors)[Research.com](https://research.com/advice/which-industries-offer-the-best-career-paths-for-software-engineering-degree-graduates)

なぜ効くか:「病気を治す/作物を改良する」という、役に立っている実感の点では最上位クラス。生物データは汚く構造化されていないので、エンジニアリングの腕の見せ所が多く、主体性も発揮しやすい。

### 3. エネルギー / 気候技術(核融合・送電網・蓄電)

物理寄りですが、ソフトの役割が急拡大しています。Commonwealth Fusion Systemsはコンパクトな核融合炉で重要な工学的マイルストーンを達成し、今十年内の商業関連実証に最も近い、HelionはMicrosoftと2028年の核融合電力の購入契約を結んだといった、SFだった話が実装フェーズに入っています。送電網最適化・スマートグリッド・蓄電制御は、まさにソフトの最適化問題です。 [Blazon Agency](https://blazonagency.com/post/top-deep-tech-startups-to-watch-2026)[Blazon Agency](https://blazonagency.com/post/top-deep-tech-startups-to-watch-2026)

なぜ効くか:エネルギーは社会インフラそのものなので「役に立っている」感が桁違い。制御・最適化・シミュレーションでCS経験が直接効きます。

### 4. 半導体 / 新しい計算ハードウェア

ソフトの停滞感の一因は「抽象化レイヤーが固まりきった」ことですが、その下のハードウェアは逆にいま再燃しています。McKinseyは半導体が新興AI技術スタックの総価値の40〜50%を占めうると分析。エッジAI推論、新方式の計算(アナログ計算など)が新しいカテゴリとして立ち上がっており、低レイヤー・性能・コンパイラ・ハード/ソフト協調設計の経験が効きます。 [StartUs Insights](https://www.startus-insights.com/innovators-guide/new-technology-trends/)

なぜ効くか:「新しい技術へのわくわく」を取り戻すなら、スタックの下に潜るのは有効な手です。問題が物理制約に直結するので、解いた実感が明確。

### 5. 宇宙 / 航空宇宙ソフトウェア

Stanfordの2026年フロンティア技術レビューでも、AI、合成生物学、暗号・コンピュータセキュリティ、エネルギー、材料科学、神経科学、量子、ロボティクス、半導体、宇宙の10分野が今後を左右する領域として挙げられています。打ち上げコストの低下で、衛星運用・地上局ソフト・軌道計算・自律制御などソフト需要が拡大中です。 [Stanford University](https://news.stanford.edu/stories/2026/01/emerging-technology-review-innovations-ai-robotics-biotech-space)

### 6. ニューロテック / ブレイン・コンピュータ・インターフェース(BCI)

まだ早期ですが兆しは明確です。90件のアクティブなBCI臨床試験が進行中で、神経インターフェースが臨床応用フェーズに入りつつある。信号処理・機械学習・リアルタイムシステムの経験が効く領域です。

### 1. 介護・高齢者ケア技術(Care Tech)

「生活に結びついた」かつ「いま採用窓が開いている」という点で、日本では最有力候補です。背景は完全に構造的で、厚労省は2040年に2022年比で約57万人の介護人材不足を見込み、介護職の有効求人倍率はすでに全職種平均の4倍超。施設は人を採って解決できないので、AIで業務を補強する方向しかなく、政府も政策・補助金・制度で後押ししている状況です。 [Hello World Japan](https://www.helloworldjapan.com/en/articles/japan-caretech-ai-engineering-opportunity)[Hello World Japan](https://www.helloworldjapan.com/en/articles/japan-caretech-ai-engineering-opportunity)

エンジニアにとって入り口が3つに分かれます:

- **介護ロボット・装着型(物理AI)**:CYBERDYNE、トヨタなど。ただし移乗支援ロボットは「40%の負担減」という当初の約束に対し、2026年時点で導入率は約3%、コストと信頼性が壁と、ハードはまだ難航中。 [Medium](https://medium.com/@jinchannel6/japan-is-running-out-of-570-000-care-workers-and-ai-just-failed-its-most-important-test-8ce324b1f359)
- **見守り・センシング(プライバシー配慮型モニタリング)**:富士通のミリ波センサーなど。監視センサーは施設カバー率35%まで来ており、プライバシー受容も進みつつある。 [Medium](https://medium.com/@jinchannel6/japan-is-running-out-of-570-000-care-workers-and-ai-just-failed-its-most-important-test-8ce324b1f359)
- **業務・書類の自動化**:ここがソフトエンジニアにとって**一番早く価値を出せる**層です。介護保険法は膨大な書類(ケアプラン、シフト記録、コンプライアンス申請)を要求し、それが日々の介護時間を奪っている。数千ページの保険規則を解釈して法的に妥当な介護文書を生成するRAGシステム、規則更新に追従するMLOpsパイプライン、レガシーな介護管理システムとのAPI連携などが具体的な仕事です。実際、管理業務の自動化は「実証済みで急速に拡大中」、AIによるシフト最適化も18%の効率改善という測定可能なROIを出しているとされ、ソフト側のほうがロボットより先に効いています。 [Hello World Japan + 2](https://www.helloworldjapan.com/en/articles/japan-caretech-ai-engineering-opportunity)

あなたの3つの不満への効き:現場の実需が明確なので**役立つ実感**は最上位。レガシーで未整備な領域が多く、**自分で問題を定義する**余地も大きい。

### 2. GovTech / シビックテック(公共サービスのデジタル化)

「社会そのもの」に最も直球で結びつく領域です。背景には、テック業界のレイオフが増えるなかで、多くのエンジニアがミッション志向の仕事に開かれてきているという人材側の変化と、市民が長い待ち時間・古いポータル・壊れたワークフローにうんざりしているという需要側の圧力があります。 [GoingVC](https://www.goingvc.com/post/the-vc-case-for-civictech-and-govtech)[GoingVC](https://www.goingvc.com/post/the-vc-case-for-civictech-and-govtech)

正直に言うと、この分野は**技術的な新しさで惹きつけるタイプではありません**。Stanfordで市民テックを教える学生自身がこう書いています——給付ポータルの構築やケース管理システムの刷新は、技術的にはほぼ解決済みの問題で、AIの最前線を押し広げるものではない。ただし、その代わりに提供できるものがある、とも:大規模で意義あるミッションに向けて作る機会であり、州・地方の行政機関は大企業より官僚主義が少なく、人々の日常に直接影響する問題への当事者責任(オーナーシップ)をより多く持てる。 [Government Technology](https://www.govtech.com/voices/how-to-attract-the-next-generation-of-civic-technologists)[Government Technology](https://www.govtech.com/voices/how-to-attract-the-next-generation-of-civic-technologists)

つまりここは、あなたの不満の「**主体的な問題意識を持ちたい/役に立っている感覚がほしい**」には非常に強く効き、「技術的わくわく」には弱い、という割り切りの分野です。逆に言えば、あなたの停滞感が「技術が枯れたこと」より「自分の仕事が誰の役に立っているか見えないこと」に根ざしているなら、これは効きます。動きとしては実際に活発で、CityBaseのような住民向けデジタル行政サービス(公共料金・許認可・税の支払い)への需要が、シカゴやフィラデルフィアなど大都市との連携を通じて拡大しているといった具体例があります。 [Purpose Jobs](https://www.purpose.jobs/blog/top-govtech-companies-2026)

### 3. デジタルヘルス / 医療情報(介護以外の医療)

高齢化と同じ人口動態に駆動され、遠隔医療、医療情報学、精密医療ツールを作るソフトエンジニアへの構造的な採用増が起きています。電子カルテ連携、診断支援、患者モニタリングなど、データとシステム統合の腕がそのまま効きます。介護(1)より医療制度寄りで、規制とドメイン知識の比重が高い分、参入はやや重いですが、社会的意義は同等です。 [Research.com](https://research.com/advice/which-industries-offer-the-best-career-paths-for-software-engineering-degree-graduates)

### 4. アグリテック / フードテック(食と農)

食という最も生活に近いテーマで、ソフトの役割が急拡大中です。2026年はAIが生産サイクル全体をつなぐ「接続レイヤー」になり、農学ツール・自律機械・施肥モデル・持続可能性プラットフォームが一つのエコシステムとして動く段階に入っています。コンピュータビジョン・IoT・最適化の経験が直接武器になり、たとえばOrchard Roboticsは独自のコンピュータビジョンとAIで樹上の果実一つひとつの特性を追跡し、収穫量管理に使えるデータを提供しているといった例があります。日本文脈では高齢化する農業従事者・地方の担い手不足という社会課題と直結します。 [ICL Group](https://www.icl-group.com/blog/future-of-agtech-2026/)[StartUs Insights](https://www.startus-insights.com/innovators-guide/agriculture-trends/)

### 5. 防災・インフラ予知保全(レジリエンス)

地震・水害の多い日本では「生活の土台」に直結する領域です。技術的にも転換点にあり、世界で年間2.5兆ドル超のコストを生む腐食問題に対し、IoTと自己修復材料を組み合わせ、リアルタイムのデータ解析に基づく予知保全へ産業をシフトさせる動きが2026年の材料科学の主要ブレイクスルーとして勢いを増しているとされています。橋梁・パイプライン・上下水道などインフラのセンシングと異常検知は、データ・MLエンジニアの仕事そのものです。地域交通(モビリティ)も近接領域で、オペレーションズ・リサーチの博士号を持つ元Googleエンジニアが設立したOntra Mobilityが、データ駆動の計画とリアルタイム最適化で都市や交通機関の利用者数を増やしているといった、最適化スキルが効く例があります。 [CAS](https://www.cas.org/resources/cas-insights/scientific-breakthroughs-2026-emerging-trends-watch)[Y Combinator](https://www.ycombinator.com/companies/industry/GovTech)
