# 小説執筆フロー

---

## フェーズ1：構想

### 1-1. アイデアの核を作る

「もし〜だったら」の表を埋める。左から順に、仮定・常識的な結果・それを踏み越えた結果を書く。

| もし〜だったら | 予想される結果（常識的） | 踏み越えた結果（脱常識的） |
| ------- | ------------ | ------------- |
|         |              |               |
|         |              |               |

踏み越えた結果が、小説の核になる。

### 1-2. テーマとモチーフを決める

- **テーマ**：読み手に伝えたい考え方・主張
- **モチーフ**：テーマを表現するための媒体（人物・時代・社会など）
- **素材**：テーマを際立たせる具体的な情景・アイテム・キーとなるもの

テーマに合わないエピソードは「まぎれ」を生じさせてドラマを薄める。追加する要素が常にテーマに沿っているか確認する。

### 1-3. 小説の全体像を把握する

以下の問いに答える。

1. この小説について、今の時点でどんなことを知っている？
2. 一番重要な登場人物は誰？どんな人物？
3. 何についてのストーリー？どんなことが起こる？
4. いつ、どこで起こる？
5. 他の人に「読むべきだ」と薦めるとしたら、どこがいい？

まだぼんやりしていて構わない。あとで変更する前提で書き出す。

## フェーズ2：人物

### 2-1. 主人公を作る

基本情報を決める。

- 名前・年齢・種族（人間？動物？）
- 外見・服装
- 外見からは想像できない特徴

内面・行動を掘り下げる。

- 喜んですること、好きな食べ物・映画・歌・本
- 他の誰にも負けないこと
- ついていない日に何をするか
- 腹を立てること・悲しむこと
- 家族・秘密・初対面の人への接し方
- 自分が好きなところ・嫌いなところ
- 3つの言葉で表すと？
- これまでの最高の出来事・最悪の出来事
- 大金を当てたら何に使うか

### 2-2. 登場人物の「裏」を考える

画面に映る「表」の生活だけでなく、画面外で起きる「裏」の生活を7〜8点考える。裏の事情が承パートの展開を支える。

### 2-3. 仲間・ライバル・悪役にも同じ問いを適用する

脇役にも宝物・動機・障害を設定すると、単純でない深みのあるストーリーになる。

## フェーズ3：プロット

### 3-1. ストーリーの3要素を決める

すべてのストーリーは「宝探し」とそのバリエーション。3要素を複数案出してから絞る。

| 宝物（主人公が最後に手に入れるもの） | 動機（探し続ける理由） | 障害（乗り越えなければならないもの） |
|---|---|---|
|   |   |   |
|   |   |   |

### 3-2. 起承転結を組み立てる

#### 起（ファーストシーン）
天地人を明確にする。舞台・主人公・敵または謎を示す。説明しすぎず、謎を残して読み手を引き込む。

進め方の選択：
- **張り手型**：驚くシーンから入り、あとで説明を補う
- **撫ぜ型**：順に見せる。迫力不足になりやすいので冒頭から小さな事件を入れてカバーする

メモ欄：

| 主人公 |   |
|---|---|
| 物語の舞台 |   |
| その他（敵・謎） |   |

#### 承（上昇する展開）
ストーリー全体の大半を占める。常に変化を出して読み手を退屈させない。

リトマス（人物・状況の反応を引き出す仕掛け）を入れる：
- **事件**：火事・事故・死亡・失業・天災など。暗くなりすぎないよう注意。
- **事情**：家庭・職場・人間関係。「隠し事」は事情を複雑化させる。
- **秘密**：読み手が知っているかどうかで緊張感・謎追いの効果が変わる。
- **伏線**：後の出来事に納得感を与える。
- **ハプニング**：伏線なしの出来事。衝撃を与える。

宝物への接近と障害の強化を交互に配置する：

| 宝物へ近づく出来事 | その後に起こる障害 |
|---|---|
|   |   |
|   |   |
|   |   |
|   |   |

#### 転（クライマックス）
ストーリーの方向が転換する。説明を入れてはいけない。無言・行動・小道具で最高潮を表現する。

「よせ玉」（物語の要素が収束して一つのつながりを見せること）を活用する。

読み手の期待に応えつつ予想を裏切る展開が理想。

メモ欄：

- 
- 
- 

#### 結（フィナーレ）
短く、低調のトーンで締める。

- **定着**：テーマを印象づけるごく短いシーン
- **余韻**：未解決なものをあえて残す

主人公は冒険前とどこか違う状態になっている。

メモ欄：

- 
- 
-

## フェーズ4：世界設定

### 4-1. 地図を描く

プロットを読み返し、物語が起こる舞台の全体地図を描く。各出来事がどこで起こるか印をつけ番号を振る。

主要な場所については詳細な見取り図も描く（主人公の部屋・仲間や敵の拠点など）。

### 4-2. タイムラインを作る

物語が始まる前から終わった後まで、時間の流れを書き出す。

タイムラインがあると：
- 物語の矛盾がなくなる
- 登場人物の行動に根拠が生まれる
- 伏線の管理がしやすくなる

主人公の一生だけでなく、親・先祖・子・子孫まで広げてもよい。ただし壮大になりすぎると執筆意欲が削がれるため、ほどほどに。

## フェーズ5：執筆準備

### 5-1. 知っていることをすべて書き出す

以下の問いに対して、箇条書きで30〜50項目を目標に書き出す。順序や相互関係は気にしない。

1. この小説についてどんなことを知っている？
2. 一番重要な登場人物は誰？どんな人物？
3. 何についてのストーリー？どんなことが起こる？
4. いつ、どこで起こる？
5. 他の人に薦めるとしたら、どこがいい？

わからないところには「？」を付けておく。

### 5-2. プロット順に並べ替える

書き出した項目をプロットに沿って並べ替え、抜けているところを把握する。抜けには「？」を付ける。

### 5-3. 「？」を潰す

どんなシーン・アクション・セリフが入ればよいかを一つずつ考える。完璧にやり終える必要はない。ある程度進めれば小説の全体像が明確になる。

## フェーズ6：執筆

手がうずいたら書き始める。

### 文章を書くときの原則

**省略**：平易な受け答えを避け、飛躍を交えて新鮮味・意外性を出す。

**葛藤**：対立・事件・小道具で内面の揺れを表現する。

**セリフ**：
- 思っていることと反対を言わせる
- 間接的な表現を使う
- 内容を意図的に飛躍させる
- テンポとリズムを意識する
- 感情を個人の言葉に落とし込む

**見せ場を作る**：スリル・闘争・ラブシーン・ショック・ドキュメンタリー性など、読み手が見入る場面を意図的に配置する。

**サスペンス**：未決・中ぶらりん・気がかり・不安・躊躇が伝わる場面を作る。

**モンタージュ**：2つ以上のシーンをつないで、別の感情や意味を引き出す。

### 執筆中のチェック

- テーマに合わない要素が混入していないか（まぎれ）
- 承は変化し続けているか
- 転で説明を入れていないか
- 結は短く、余韻があるか

## フェーズ7：投稿・入稿

### Web投稿（小説家になろう・カクヨム）

VSCodeで書いた`.txt`の内容をブラウザの投稿画面に貼り付ける。サイトごとに記法が異なるため変換が必要。

| 記法 | 小説家になろう | カクヨム |
|---|---|---|
| ルビ | `｜漢字《かんじ》` | `｜漢字《かんじ》` |
| 傍点 | `｜傍《・》点《・》` | `《《傍点》》` |

複数サイトへ同時投稿する場合は変換ツール（有志公開）を使う。

### 印刷入稿（同人誌）

VSCode（`.txt` / `.md`）→ Wordに貼り付けてレイアウト → PDF書き出し（フォント埋め込み）→ 印刷所入稿

多くの印刷所はPDF入稿を推奨。Word直接入稿はレイアウト崩れのリスクがある。
