### 2026.07.11 ロング走 18km(平均6:13/km・獲得標高315m)
実績:
 - 距離18.00km / 時間1:51:52 / 平均ペース6:13/km(最速4:38/km)
 - 平均心拍153 / 最小104 / 最大177、平均ケイデンス174spm(87×2)
 - 消費1415kcal(炭水化物59% / タンパク質3% / 脂肪38%)
 - ラップ:序盤6:02〜6:08で安定 → Lap16〜18で6:32〜6:43へ失速(+30〜40秒/km)
 - 当初22km(6:30/km)予定に対し18kmで終了。20km完遂できず

レビュー:
 - 目標ペース(6:03〜6:10/km)前後を余裕のある心拍で刻めており、走力・基礎持久力は計画の想定内。
 - 後半の失速は心拍が変わらずペースだけ低下する典型的なカーディアック・ドリフト(暑熱下のデカップリング)。本人分析どおり主因は(1)急な気温上昇。脇役として(2)先週の練習見送りによる暑熱順応の一時的な鈍化。走力低下ではなく「同じ努力の変換効率」の低下と判断。
 - 20km未達は不安材料だが、目標ペースを余裕心拍で維持できている事実から、本番の距離耐性は今後の積み上げで十分射程内。

対策・方針:
 - 土台(ロング走を段階的に伸ばす)は現計画のまま継続。メニューの全面変更は不要。
 - 追加すべき一点:ペース特異的刺激(マラソンペース走/閾値走)。ロング走の最後5〜8kmを目標ペース(6:05〜6:10/km)に上げて終える形で「疲れた脚でのペース維持力」を鍛える。
 - 暑い日はペースではなく心拍で管理し、垂れても気にしない(暑熱順応を優先)。給水・電解質を早めかつこまめに。
 - 週抜けを最小化する(残り約10週。2〜3回続けて抜けると最長走38kmまでの積み上げが間に合わなくなる)。

### 2026.07.18 ペース走 10km(平均6:27/km・獲得標高190m)
実績:
 - 距離10.01km / 時間1:04:25 / 平均ペース6:27/km(最速4:47/km)
 - 平均心拍142 / 最小93 / 最大164、平均ケイデンス92spm(184)
 - 消費741kcal(炭水化物57% / タンパク質1% / 脂肪42%)
 - 獲得標高190m(下り175m)、高度94m
 - ラップ:6:13〜6:43でおおむね安定(ベスト6:13・平均6:26)。心拍ゾーン3が52分18秒と大半を占める
 - ラップ心拍は前半129〜143 → 後半142〜152へ微増(軽度のドリフト)

レビュー:
 - ペース・心拍ともに安定した良質なゾーン3中心の走り。起伏(上り190m/下り175m)のあるコースでの脂づくりに効くロング質のペース走
 - 後半の心拍ドリフトは約15bpmと軽度。秋の涼しい時期と比較すれば暑熱順化の進捗の指標になる
 - ケイデンス92spm(184)は目標水準に到達。ロング走で疲労時に落ちる傾向との対比で良好

膝痛への対応(今回ピッチを上げて膝負担軽減を狙った件):
 - ピッチを上げて歩幅を縮める方向は正しい(着地時の膝蓋大腿関節への衝撃が減る)。ただし既に92spmと良水準のため、これ以上ピッチで削れる負担は限定的
 - 主因として疑わしいのは下り175mのエキセントリック負荷。痛みが続く間は下りをウォーク化するか平坦コースへ一時変更

リカバリー手段の検討:
 - マッサージガン:大腿四頭筋・ふくらはぎ・腸脛靭帯周りの筋腹には有効(DOMS軽減にエビデンスあり)。膝関節そのものや腱・骨の出っ張りへの直接当ては避け、痛む箇所の「上下の筋肉」に使う
 - 湿布:経皮NSAIDsの局所鎮痛にはエビデンスあり。ただし対症療法で原因は治らない。「痛みが消えたからいつも通り走る」は最も危険
 - 根本対策:大腿四頭筋・臀筋の筋トレ(スクワット・片脚ステップダウン)で下りの衝撃吸収力を強化
 - 走行中に痛みが増す・数週間引かない場合は、9月レースを考慮し早めに整形外科・スポーツ専門医で受診(痛みの原因特定は医師の確認を優先)
### 2026.07.19 ロング走 20km(平均6:38/km・獲得標高370m)
実績:
 - 距離20.01km / 時間2:12:28 / 平均ペース6:38/km(最速4:23/km)
 - 平均心拍149 / 最小103 / 最大173、平均ケイデンス176spm(88×2)

 - 当初22km(6:30/km)予定に対し20kmで終了。前回18kmから距離は前進

レビュー:
 - 前回同様、後半は心拍がほぼ横ばい(144〜156)のままペースだけ低下するデカップリング。マラソン課題の「30km以降の失速」が20km時点でミニチュア版として出た形
 - 使用エネルギーのチャートで約1時間(≒9〜10km)から脂肪消費比率が上昇し、体感疲労の増大と一致。グリコーゲン枯渇の兆候が早めに出たと解釈

 - ケイデンスは88spm(片脚)で目標92を下回る。疲労でピッチが落ちる悪循環に注意

対策・方針(脂肪メイン化を遅らせる):
 - 最重要:レース中の糖質補給。1時間30〜60g(訓練で90gまで)を摂りグリコーゲン消費を肩代わり。長いロング走で必ずジェル・ドリンクを試し胃腸を慣らす
 - カーボローディング(レース2〜3日前〜当日3〜4時間前の糖質食)でスタート時グリコーゲンを満タンに
 - イーブンペースで入る(今回の5:54の突っ込みを抑える)
 - 中長期:Zone2ロング走+糖質控えめの回で脂肪酸化能力を底上げ(補給ありの質の高い回とバランス)。ケイデンス92への回復
 - 暑熱対策(涼しい時間帯・順化・当日冷却)。夏のデータは「悪条件版」と割り引く
 - 次回ロング走で「45〜60分ごとに糖質○g+イーブンペース」を試し、同じチャートで脂肪シフトが後ろへずれるか検証
