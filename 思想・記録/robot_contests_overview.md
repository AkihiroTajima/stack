# ロボットコンテスト概要まとめ

調査日：2026年6月29日

---

## 1. ロボット相撲（全日本ロボット相撲大会）

| 項目 | 内容 |
|------|------|
| 主催 | 富士ソフト株式会社（一般の部）、公益社団法人全国工業高等学校長協会（高校生の部） |
| 開始年 | 1989年（プレ大会）、1990年第1回 |
| 開催地 | 地区予選各地、決勝大会：両国国技館（東京） |
| 参加資格 | 一般の部：誰でも可。高校生の部：全工高加盟校の高校生 |
| 競技形式 | 土俵上でロボット同士が相手を押し出す。先に2本取った方が勝ち、試合時間3分 |
| 部門 | 自立型／ラジコン型、3kgクラス（20cm×20cm）／500gクラス（10cm×10cm） |
| 土俵 | 3kg級：直径154cm、冷間圧延鋼板 |
| 特記事項 | 世界30カ国以上・延べ8万人が参加する国際的な大会。世界一の「ロボット横綱」を決定 |
| 公式サイト | https://www.fsi.co.jp/sumo/ |

## 2. かわロボ（かわさきロボット競技大会）

| 項目 | 内容 |
|------|------|
| 主催 | かわさきロボット競技大会実行委員会（旧：川崎市産業振興財団） |
| 開始年 | 1994年（平成6年度） |
| 開催地 | 川崎市産業振興会館（神奈川県川崎市）、2025年は慶應義塾大学矢上キャンパス |
| 参加資格 | 高校生以上、2名以上4名以下のチーム |
| 競技形式 | 脚・腕構造を持つラジコン型ロボットによる1対1の格闘（バトルロボット部門）。190cm四方のリング上で対戦 |
| 特記事項 | 「若者のものづくり登竜門」として技術者育成が目的。2024年より運営主体が実行委員会に移行。2025年で第30回 |
| 公式サイト | https://kawasaki-sanshinkaikan.jp/robo/ |

## 3. マイクロマウス（全日本マイクロマウス大会）

| 項目 | 内容 |
|------|------|
| 主催 | 公益財団法人ニューテクノロジー振興財団（NTF） |
| 開始年 | 1980年（日本での全国大会）。競技自体は1977年IEEEが提唱 |
| 開催地 | 東京工芸大学厚木キャンパス等（毎年2月） |
| 参加資格 | 社会人・大学生・高校生など。地区大会で完走した者が全国大会に出場可 |
| 競技種目 | ①マイクロマウス競技（ハーフサイズ迷路）②クラシックマウス競技（16×16迷路）③ロボトレース競技（白線追従） |
| 競技形式 | 自律ロボットが未知の迷路を探索しゴールまでのタイムを競う（操作一切不可）。ファイナルは32×32迷路 |
| 特記事項 | 日本で最も歴史の古いロボットコンテストの一つ。シンガポール・韓国・台湾等海外からも参加。事実上の世界大会 |
| 公式サイト | https://www.ntf.or.jp/ |

## 4. レスキューロボットコンテスト（レスコン）

| 項目 | 内容 |
|------|------|
| 主催 | 一般社団法人レスキューロボットコンテスト実行委員会 |
| 開始年 | 2000年（プレ大会）、2001年第1回 |
| 開催地 | 神戸市（主に兵庫県立総合体育館等）、毎年8月 |
| 参加資格 | 高校生・高専生・大学生・社会人。参加資格の制限なし |
| 競技形式 | 地震被災市街地の1/4スケールフィールドで、要救助者人形「ダミヤン」を遠隔操作ロボットで救出。操縦者はフィールドに立ち入れず、車載カメラ映像のみで操作 |
| 発端 | 1995年阪神・淡路大震災でのレスキューロボットの必要性を契機に提案 |
| 理念 | 「技術を学び 人と語らい 災害に強い世の中をつくる」 |
| 公式サイト | https://www.rescue-robot-contest.org/ |

## 5. ロボカップ（RoboCup）

| 項目 | 内容 |
|------|------|
| 主催 | ロボカップ国際委員会（The RoboCup Federation）、日本：NPO法人ロボカップ日本委員会 |
| 開始年 | 1997年第1回世界大会（名古屋）。日本委員会は1999年設立 |
| 開催形態 | 毎年7月頃に世界大会、5月にジャパンオープン（国内大会） |
| 参加資格 | シニアリーグ（研究者・学生等）、ジュニアリーグ（19歳以下） |
| 競技リーグ | サッカー（小型・中型・ヒューマノイド等）、レスキュー、＠ホーム（家庭用ロボット）、産業用等 |
| 目標 | 「2050年までに人間のサッカー世界チャンピオンに勝てる自律型ロボットチームを作る」 |
| 特記事項 | 世界規模の国際プロジェクト。AIと自律ロボット技術の研究促進が目的。Amazon Roboticsもロボカップ参加者発祥 |
| 公式サイト | https://www.robocup.or.jp/ |

## 7. 知能ロボコン（知能ロボットコンテストフェスティバル）

| 項目 | 内容 |
|------|------|
| 主催 | ロボット競技会実行委員会、共催：仙台市教育委員会、日本ロボット学会等 |
| 開始年 | 1980年代（国内最古級の自律ロボットコンテスト） |

| 特記事項 | 国内でも長い歴史を持つ完全自律ロボットの高度な競技大会。大学教員・学生・有志によるボランティア運営 |
| 関連サイト | http://www.inrof.org/irc/ |

## 11. BattleBots

| 項目 | 内容 |
|------|------|
| 主催 | BattleBots, Inc.（Greg Munson・Trey Roski創設） |
| 開始年 | 1999年（ZDTV配信）、2000年よりテレビ番組化 |
| 開催地 | アメリカ（主にカリフォルニア州） |
| 競技形式 | ラジコン型ロボット同士が「ロボコンバット（ロボット格闘）」を行い相手を破壊・動作不能にする。3分間の試合、最大重量250ポンド（約113kg） |
| 武器 | 回転ノコギリ・ハンマー・フリッパー・火炎放射等なんでもあり（放射性物質等は禁止） |
| 放送歴 | コメディセントラル（2000〜2002）→ABC（2015〜2016）→ディスカバリーチャンネル（2018〜2023）→Destruct-A-Thon等 |
| 特記事項 | 英国Robot Warsを源流とする。エンターテインメント性重視のテレビ番組形式が特徴。世界的知名度が高い |

## 12. 鳥取ローバーチャレンジ（Tottori Rover Challenge）

|------|------|

| コンセプト | 「鳥取砂丘から月へ！未来の探査技術を切り拓け！」。宇宙産業人材育成の登竜門を目指す |

## 13. 国際宇宙ロボットコンテスト（「きぼう」ロボットプログラミング競技会 / Kibo-RPC）

| 項目 | 内容 |
|------|------|
| 主催 | JAXA（宇宙航空研究開発機構）、NASA |
| 形式 | 国際宇宙ステーション（ISS）「きぼう」モジュール内の船内ドローン「Int-Ball」（JAXA）・「Astrobee」（NASA）をプログラミングしてミッションを解く国際競技 |
| 参加資格 | 世界各国の大学生・大学院生チーム |
| 競技形式 | 宇宙飛行士の補助業務を模したミッションをロボットに自律実行させる。コードを事前提出しISSの実機で動作 |
| 特記事項 | 実際に宇宙空間で動作する点が他のロボコンとは一線を画す。「宇宙でプログラムが動く」体験が最大の特徴 |
| 公式サイト | https://humans-in-space.jaxa.jp/biz-lab/kuoa/kibo-rpc/ |

|------|------|
| 主催 | 姫路科学館 |
| 開始年 | 1990年代（第36回が2025年開催） |
| 開催地 | 姫路市（姫路科学館・JR姫路駅西側自由通路等）、年1回（7月頃） |
